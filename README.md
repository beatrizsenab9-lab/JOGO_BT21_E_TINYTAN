JOGO BTS - RESGATE BT21
========================

COMO ABRIR
1. Extraia a pasta JOGO_BT21_E_TINYTAN.
2. Abra o arquivo index.html no navegador.
3. Clique em INICIAR JOGO e siga as instrucoes.
4. Mantenha todos os arquivos e pastas juntos. Nao mova imagens ou arquivos HTML para fora das pastas.

ESTRUTURA
- index.html: tela inicial.
- instrucoes.html: regras e escolha do integrante do BTS.
- mapa-inicial.html: inicio das fases.
- fase-*.html: oito fases dos mascotes.
- sucesso-*.html: telas de conclusao de cada fase.
- mapa-*-concluido.html: mapas de progresso entre as fases.
- Cenario BT21, BT21 Separado e arquivos PNG: imagens utilizadas pelo jogo.
